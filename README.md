# Tarjeta de Presentación Digital — Brunella Lorca

Tarjeta de presentación digital interactiva y responsive diseñada para **Brunella Lorca** (Directora Creativa en *InteliGRAFIX Studio*).

## 🚀 Características
- **Estilo Visual**: *Liquid Glass* (cristal esmerilado / acrílico translúcido inspirado en iOS / Apple VisionOS).
- **Llamada a la Acción (CTA)**: Botón destacado de WhatsApp ("Pídeme presupuesto") con mensaje preconfigurado.
- **Guardar Contacto**: Generación y descarga directa en el navegador de archivo `vCard (.vcf)` compatible con iPhone y Android.
- **Código QR**: Modal integrado con código QR dinámico para escaneo presencial en dispositivos móviles.
- **Compartir**: Integración con Web Share API nativa y fallback de copiado al portapapeles.
- **Responsive**: Optimizado para dispositivos móviles y visualización en pantallas de escritorio.
- **Autocontenido**: Todo el código (HTML, CSS y JavaScript) en un único archivo sin dependencias externas pesadas.

## 🛠️ Tecnologías
- HTML5 Semántico
- CSS3 (Vanilla CSS, Glassmorphism, CSS Grid, Flexbox, Micro-animaciones)
- JavaScript Vanilla (Web Share API, Blob API para vCard, Clipboard API)
